## 本目录文件

| 文件 | 状态 | 说明 |

| `global-contract.md` | ⬜ 尚无文件 | 由 **01** 初始化；此后 02 / 03 / 棕地增量，版本须递增 |

## 谁可以改什么

| 产物 | 绿场 | 棕地 |
|------|------|------|
| `global-contract.md` | 01 初始化；02 / 03 增量 | 任务改跨模块约定时回写，版本 +0.1 |
| `progress.md` | 01 建表；02 → 📝；03 → 🔍；**仅 04 / 维护者 → ✅** | 不占用「未开始」行；必要时备注列留指针 |
| `modules/Fxx-*.md` | **02 生成正文**；03 可按层级 1 回写接口 / 模型 / 路径等（须 `<!-- 回写修正 -->`） | 已 ✅ 后的行为修补走 `specs/`，一般不再新开 Fxx |

棕地过程稿不放本目录，见 [`../specs/`](../specs/)。
