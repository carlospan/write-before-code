# reference/

本目录放**可检索的事实与约束**（契约、进度、模块规格）。干活时查阅；叙事与「为什么」不在这里。

## 本目录内容

| 路径 | 状态 | 说明 |
|------|------|------|
| `global-contract.md` | ⬜ 尚无文件 | 由 **01** 初始化；此后增量须升版本 |
| `progress.md` | ⬜ 尚无文件 | 由 **01** 初始化；绿场 ✅ 仅 04（或维护者）写入 |
| [modules/](./modules/) | ⬜ 空 | 由 **02** 产出 `Fxx-*.md`；见 [modules/README.md](./modules/README.md) |

**不预建空壳**：契约、进度、模块文档由绿场阶段直接创建完整文件。编码约定：**垂直切片**（API + 约定界面一起验收）。

## 谁可以改什么

| 产物 | 绿场 | 棕地 |
|------|------|------|
| `global-contract.md` | 01 初始化；02 / 03 增量 | 改跨模块约定时回写，版本 +0.1 |
| `progress.md` | 01 建表；02 → 📝；03 → 🔍；**仅 04 / 维护者 → ✅** | 不占用「未开始」行；必要时备注留指针 |
| `modules/Fxx-*.md` | **02 生成正文**；03 可按层级 1 回写（须 `<!-- 回写修正 -->`） | 已 ✅ 后的行为修补走 `specs/` |

棕地过程稿见 [`../specs/`](../specs/)。设计动机见 [`../explanation/`](../explanation/)；操作步骤见 [`../how-to/`](../how-to/)。
