## 用途

棕地迭代的**过程稿落点**：短规格、实现步骤、验收判据、HITL 批点，以及可选的方案 / 回执 / 验收记录。  
维护者与 IDE Agent 以本目录文件为真源，不以聊天记录为准。

---

## 命名约定

| 类型 | 命名 | 说明 |
|------|------|------|
| 主任务包（必有） | `YYYY-MM-DD-短名.md` | 从 `_template.md` 复制改名 |
| 方案（可选） | `YYYY-MM-DD-短名-方案.md` | 大改动时另附实现思路 |
| 回执（可选） | `YYYY-MM-DD-短名-回执.md` | 编码完成后的自验摘要 |
| 验收记录（可选） | `YYYY-MM-DD-短名-验收记录.md` | 维护者 HITL / 书面验收 |

默认采用 **IDE 单线**：同一会话完成起草 → 编码 → 工程自验 → 回写；维护者只做 HITL。过程文件按需增减，不必凑齐全套附件。

## 纪律提要

1. **未闭环不归档**；闭环须已写 `INDEX.md`，然后整组迁入 [`../archive/`](../archive/)，保持本目录只含进行中项。

4. 绿场新模块：无 01 产物或要改架构 → 满配 `01→04`；01 已在且不改架构、维护者明示 → 轻量档 `02→04`。不要用任务包代替尚未落地的模块规格。
