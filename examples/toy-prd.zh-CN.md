# 仅作示例 — 非真实产品

**[English](toy-prd.md)** · **[中文](toy-prd.zh-CN.md)**

虚构产品 **Sticky Notes CLI** 的玩具 PRD，仅用于演示模板。

---

## 定位

本地个人便签 CLI：新增、列出、按 id 删除。单用户；无账号、不同步。

## 明确不做

云同步、多用户、富文本、GUI。

## 功能

### F-1 新增便签

- **做什么**：用文本创建便签并分配稳定 id。
- **验收**：WHEN 执行 `notes add "buy milk"` THEN 持久化一条带 id 的便签并回显。

### F-2 列出便签

- **做什么**：打印全部便签（id + 正文）。
- **验收**：WHEN 执行 `notes list` THEN 每条便签一行输出。

### F-3 按 id 删除

- **做什么**：按 id 删除一条便签。
- **验收**：WHEN 对已有 id 执行 `notes delete <id>` THEN 该条消失；未知 id → 明确错误且不改动。

## 约束

- 客户端：CLI · 存储：本地文件 · 鉴权：无
- 成功：三命令在全新安装、无网络下可用。
