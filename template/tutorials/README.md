## 写教程时注意

- 一步一目标；给出「做到这里应看到什么」。  
- 不要把 how-to 的完整生产步骤原样塞进来。  
- 与 [how-to/](../how-to/) 分工：学会走通 → tutorials；以后反复查步骤 → how-to。  
- 不要绑定某个真实客户项目的业务细节。
